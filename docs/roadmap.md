# Engineering roadmap

1. Add customer/provider identity with secure sessions or OIDC and role-based access.
2. Replace static service catalogue with managed catalogue and provider availability data.
3. Introduce audited booking assignment and provider workflow.
4. Add API integration tests using an ephemeral MongoDB test instance.
5. Add dependency/image scanning, SBOM generation, signed image provenance, and release promotion.
6. Add managed hosting, TLS, centralized observability, backup/restore automation, and SLOs.
7. Add payment integration only with a compliant provider; do not store card data.
